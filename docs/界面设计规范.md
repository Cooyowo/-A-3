# 界面设计规范（UI Spec · v1）

> **这份文件是什么**：把用户从 M2 开始提出的**全部界面与体验要求**汇总成一份可执行清单，避免换会话/换分支后遗忘。
>
> **权威性**：游戏规则以 `docs/玩法说明.md` 为准；**界面与交互口径以本文为准**（本文是用户逐条口述整理，未经用户确认的推断会标注「推断」）。
>
> **状态图例**：`✅ 已实现` / `🔄 部分实现` / `⬜ 未实现` / `↩︎ 已废弃（用户后来否掉）`
>
> 最近更新：2026-11-16（对应提交 `ab74fcb`）

## 1. 全局

| # | 要求 | 状态 |
|---|---|---|
| G-01 | **强制横屏**：电脑浏览器 + 手机横屏；竖屏或偏高的窗口只显示「请把手机横过来使用」，不做竖屏布局 | ✅ |
| G-02 | 页面**禁止选中文字**（拖动牌、点按钮时不要选中文本）；输入框除外 | ✅ |
| G-03 | 中文为主；文字必须与所在背景有区分度，**不能全用白色/黄色** | ✅ |
| G-04 | 配色方向：**低饱和、清新、干净通透**；拒绝暗沉厚重（不要墨绿台球桌、不要深褐底） | ✅ |
| G-05 | 按钮文字要够大；「不出」等状态文字要醒目 | ✅ |
| G-06 | 按钮 hover：轻微放大 + 提亮 + 柔和阴影，过渡顺滑、不做夸张特效 | ✅ |

## 4. 出牌区与状态展示

| # | 要求 | 状态 |
|---|---|---|
| C-01 | 出牌 /「不出」放在**靠牌桌中心的一侧**：左家→头像右边、右家→头像左边、顶家→头像下边 | ✅ |
| C-02 | 「不出」是**主要状态文字**，字号大（约 0.42~0.46 × 手牌高）、加粗、带轻微描边/阴影；**不要灰框/药丸底** | ✅ |
| C-03 | 每人的出牌 /「不出」**一直保留到他下次出牌才更新**（不随「墩」清空） | ✅ |
| C-04 | **轮到某人行动时，他自己那侧上一轮的牌/「不出」先隐藏**，打出新的牌再显示 | ✅ |
| C-05 | 明牌 ♠3/♠A：**自己明牌 → 显示在桌面中央**；**别人明牌 → 显示在他自己的出牌区**；显示到「开始游戏前倒计时」结束 | ✅ |
| C-06 | 回牌：**自己回出的牌 → 桌面中央**；**别人回出的牌 → 他自己的出牌区** | ✅ |
| C-07 | 倒计时统一做成**小闹钟**：外圈环形进度（随时间消退）+ 中间剩余秒数 | ✅ |
| C-08 | 他人回合的倒计时显示在**头像旁**（左家右上、右家左上、顶家右侧），不压牌；自己的倒计时在按钮条里；回牌阶段在桌面中间放一个**所有人可见**的大闹钟 | ✅ |
| C-09 | **同一环节只允许有一个倒计时**（曾出现切换视角后 15/13/23 秒两个计时并存 → 已修：座位闹钟只在出牌阶段显示） | ✅ |
| C-10 | 「轮到 x 号位 领出」文字用深色（原来浅色与桌面区分度低） | ✅ |

## 5. 手牌与操作条

| # | 要求 | 状态 |
|---|---|---|
| H-01 | 手牌**贴在屏幕底端**（不留空隙），横向单排 | ✅ |
| H-02 | 牌高 = **3/17 屏幕高**（原 2/7 太大，两排会挡桌面）；打出的牌 = 0.58 倍；小牌 = 9dvh | ✅ |
| H-03 | **永远单排**：14/15/25 张靠叠放压紧，每张露出左上角点数+花色（原两排方案废止） | ✅ |
| H-04 | 牌面：**左上角数字在上、花色紧贴其下**；点数 ≈ 0.40 牌高、花色 ≈ 0.34 牌高；中央只留很淡的花色水印 | ✅ |
| H-05 | 选中牌**只向上浮起 + 金色描边**，不加层级，不能遮住右侧相邻手牌 | ✅ |
| H-06 | 供牌来的牌：**开始游戏之前**用暖金色区分，开始游戏后自动复原 | ✅ |
| H-07 | 按钮顺序：**【倒计时、不出、提示、出牌、清空】**（用户后来把倒计时提到最左） | ✅ |
| H-08 | **领出时隐藏「不出」**（不能过牌）；手里没有任何能出的牌时**隐藏「出牌」「清空」**，只剩【倒计时、不出、提示】 | ✅ |
| H-09 | 回牌阶段按钮条：`已选 x/N`、`回牌`、`自动选最小`；**最多只能选 N 张**（多选给提示、不能出现 x>N）；♠3/♠A 不可选并提示 | ✅ |
| H-10 | 挑回牌按钮：只有**倒计时 +「选这张」**，样式与出牌按钮一致；**不要**「x 号位 挑回牌」之类文字 | ✅ |

## 6. 流程与阶段表现

标准一局：

```
发牌（每人 13 张，无动画）
  → 供牌倒计时（输家要供的牌标色；双地者可选择是否明牌）
  → 倒计时结束后执行供牌（飞牌动画到赢家）
  → 回牌（所有赢家同步各自选牌）
  → 挑回牌（按供牌大小顺序轮流）
  → 锁定窗口（倒计时，无文字）
  → 开始游戏（出牌）
  → 结算 → 下一局
```

| # | 要求 | 状态 |
|---|---|---|
| F-01 | **发牌动画**先加过、后来用户要求**去掉**（绿色牌挡视野）；切牌不再播放 | ↩︎ |
| F-02 | 供牌倒计时期间：输家要供的牌**变颜色**（让供方看清）；双地者此时可选**明牌** | ✅ |
| F-03 | 明牌后：**立刻结束倒计时、跳过供牌**，把 ♠3/♠A 展示出来，直到「开始游戏前倒计时」结束，由明牌者首发 | ✅ |
| F-04 | 不明牌：倒计时结束后才把输家的牌移到赢家（飞牌动画），然后开始回牌 | 🔄 现在是「引擎瞬间完成 + 界面补动画」，**要改成真正的「倒计时结束才执行」** |
| F-05 | 回牌**同步**：所有赢家各自回牌，切到谁就能操作谁；不是「你先回我再回」 | ✅ |
| F-06 | 回牌倒计时以**最后一个点击回牌的赢家**为准：若最后一个也交了且倒计时未结束，就提前结束 | ✅（引擎在所有赢家交完后自动推进） |
| F-07 | 回牌超时（自己没点）：自动还**最小**的合法牌 | ✅ |
| F-08 | 挑回牌：按「上交最大牌」从大到小轮流；超时自动拿**最大**的一张回牌 | ✅ |
| F-09 | 双地明牌输、供 12 张（只有 1 个供牌方）：**跳过手动挑选**，短暂等待后整批自动转回他手里（现在先 3 秒、之后每 200ms 一张） | ✅ |
| F-10 | 锁定窗口：**不弹窗、不显示任何锁定文字**；桌面中间只显示倒计时；符合条件的人在自己手牌上方看到「提前锁定」按钮（点了即锁定）；其他玩家看不到谁要锁 | ✅ |
| F-11 | 平局后的下一局：锁定窗口显示「本局平平无奇」+ 倒计时 | ✅ |
| F-12 | 每个环节在桌面中间有阶段提示（发牌/明牌/供牌/回牌/挑回牌/开始游戏/结算） | 🔄（提示已大幅精简，锁定与回牌只剩倒计时） |
| F-13 | 供牌/回牌阶段**不要弹窗**，一切在牌桌上完成 | ✅ |
| F-14 | 系统（引擎）不能「发完牌立刻把输家的牌塞给赢家」——必须等倒计时结束（同 F-04） | ⬜ |

**默认时长（可在右上「设置」里实时改）**

| 参数 | 默认 | 说明 |
|---|---|---|
| 发牌动画 | 1200ms | 已废弃（不播动画），参数保留 |
| 明牌/供牌倒计时 | 4000ms | 期间标色 + 双地可明牌 |
| 供牌飞牌 | 800ms | 牌移动到赢家的动画 |
| 回牌倒计时 | 20000ms | 所有赢家共用一条 |
| 挑回牌倒计时 | 15000ms | 每位供牌方一条 |
| 开始游戏前倒计时 | 5000ms | 原「锁定窗口」 |
| 出牌回合 | 30000ms | 仅展示，不代打 |
| 整批转移间隔 | 350ms | 双地明牌输 12 张时；实际先用 3000ms 再 200ms/张 |

## 7. 结算窗口

| # | 要求 | 状态 |
|---|---|---|
| R-01 | 底色**浅暖米色**（低饱和、清新），**不要暗沉深褐/深色**；圆角柔和、轻微朦胧阴影、整体干净通透 | ✅ |
| R-02 | 字体颜色与底色有区分度；标题字号放大醒目、表头适中、表格内容清爽不拥挤，**大小字落差不要过大** | 🔄（底色/字号改过一轮，间距层级还要再调） |
| R-03 | 列：**名次 / 座位 / 身份 / 得分/分 / 剩余/张 / 获取** | ✅ |
| R-04 | 「队伍」列改成「**身份**」：持 ♠A 显示 `♠A`、持 ♠3 显示 `♠3`、双地显示 `♠3♠A`、非地主方显示 `-` | ✅ |
| R-05 | 「获取」列表示下一局供牌收支：输家红字 `-n`、赢家绿字 `+n`、平局全 0 | ✅ |
| R-06 | 获取数字必须**牌数守恒**：双地明牌输 → 输家 −12、其余三家各 +4；双地不明牌输 → −6 / 各 +2；非双地大赢 −2 / 各 +1，小赢 −1 / 各 +0.5→实际引擎为整数分配 | ✅ |
| R-07 | 删掉底部「供牌 下一局……」与「首发……」两行文字 | ✅ |

## 9. 明确延后 / 不做

1. **热座隐藏信息**：同屏共享，物理上无法隔离（谁有锁定资格、别人手牌都能被旁边看到）；M3 每人一台设备后由服务端隔离。
2. **每个赢家各自独立回牌倒计时**：需要服务端并行回牌窗口，归入 M3。
3. **断线重连、托管、回合计时**：M3 阶段再做（v1 无托管）。
4. **发牌动画**：用户已明确不要。

## 10. 给接手开发者/AI 的提示

- 改动界面时按 §3~§7 逐条核对，尤其「靠中心摆放」「单排手牌」「一句话状态」「不要弹窗」这几条最容易回退。
- 样式集中在 `apps/web/src/styles/`：`layout-v3.css`（场景与摆位）、`poker.css`（牌与操作条）、`seat.css`（座位与闹钟）、`flow.css`（流程层/结算/设置）、`panels.css`（结算浮层基础）。
- 时间/种子等可调参数在 `apps/web/src/game/store.ts` 的 `DEFAULT_TIMINGS`；UI 入口在 `App.tsx` 的「设置」。
- 改完跑：`npm.cmd test`、`npm.cmd run typecheck`、`npm.cmd run build --workspace @a3/web`。
