## M2 界面重做（横屏斗地主风格）—— 2026-11-15

**前置提交**：`88807c7`　**本次提交**：见 `git log` 最新一条

**为什么重做**：第一版竖屏界面经用户试玩后反馈——页面提示文字太多显得杂乱、牌太小、墨绿色配色不好看。按用户给的布局方向整体重做成**横屏斗地主风格**。

**新布局（用户定的口径）**

- **强制横屏**：电脑浏览器、手机横屏；竖屏直接显示「请把手机横过来使用」，不做竖屏样式。
- **四个座位环绕椭圆牌桌**：底部自己（横向手牌）、顶部一名、左上、右上各一名；三名对手只显示**牌背 + 剩余张数**，不显示手牌。
- **牌桌**：椭圆形台面（比原来的墨绿更亮的绿）+ 木色边框；中央出牌区上方小字提示「轮到谁」。
- **自己的牌**：位于页面底端，牌底距页面底端 1/14 页高；牌高 = 2/7 页高；牌面中央大点数 + 大花色（合计约占牌高一半），左上角小角标保证叠放时也能认出；选中轻微上浮 + 金色高亮。
- **按钮栏**（在牌上方）：`不出` / `提示` / `剩余时间` / `出牌` / `清空`，轮到自己出牌才出现，出牌或不出后消失。
- **每个人打出的牌/「不出」**：自己的显示在桌面中央，其余三家的显示在各自头像旁边；一直保留到下一墩开始（见下面 `trickNo`）。
- **倒计时**：当前行动者头像旁显示圆形进度图标；数字只在剩余 ≤10 秒时显示；**只是视觉**（v1 无托管，到 0 不会自动代打）。
- **身份与名次**：只有**公开的地主**（明牌、或打出过 ♠3/♠A）头像旁显示「地主」徽标；非地主/未公开什么都不显示。名次改用**金/银/铜奖牌图标**，不写「第 N 名」。

2. **身份公开规则**：只在「自己行动 / 明牌后 / 结算后 / 该座位打出过地主牌」时显示身份，其它情况显示「身份未公开」。
3. **锁定窗口没有 5 秒倒计时**：热座场景由每个达标玩家自己拨开关后点「开始出牌」推进（Q-002：热座禁用倒计时；Q-053 的 5 秒固定窗口是 M3 服务端口径）。

5. **不用 SSR 做界面测试**：zustand v5 的 SSR 快照永远取初始 state，静止渲染测不出其它阶段，所以界面测试统一用 jsdom + Testing Library 真实挂载。

1. 热座是同屏共享，**隐藏信息在物理上无法真正隔离**（锁定资格、明牌选择都能被旁边的人看到）；M3 每人一台设备后由服务端隔离手牌。
2. 出牌阶段没有回合计时与托管（Q-033 v1 不做）。
3. 手牌 13 张时叠放后每张可见约 22px，点选需要一点准头；真机验收若觉得难点，可以把叠放比例放宽或加「点中间区域放大」。
4. 结算面板在 844px 高度下需要轻微滚动（底部「下一局」按钮可见，供牌预告部分需要滑一下）。
